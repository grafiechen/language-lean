# MOJi 辞书背词模块参考与改版方案

调研日期：2026-10-03。用户提出希望背词模块参考MOJi辞书；本轮先明确页面和交互方向，业务规则仍使用已确认的设计。以下改版内容是本项目的方案，不代表MOJi的内部实现。

## 来源与核实范围

主要依据[MOJi官方全产品说明书](https://webpc-debugten.mojidict.com/support/)的“MOJi辞書APP端”背词部分，页面标注最后更新2026年7月。官方资料同时包含MOJiTest等产品，参考时区分产品；没有使用MOJiTest的复习周期作为本项目规则。

官方资料显示，辞书背词由计划首页、学习列表、新学/复习、测试和听词组成。首页使用词书卡片与统计；列表支持遮挡和筛选；测试包含回忆自评等模式；听词有卡片/列表、循环及播放设置。来源：[官方说明书](https://webpc-debugten.mojidict.com/support/)。

视觉参考：[官方背词攻略首页截图](https://oss.mojidict.com/article/images/d3b2af23-0514-4650-a1c7-b4f274a46d43.JPG?x-oss-process=style%2Farticle-content)、[学习列表截图](https://oss.mojidict.com/article/images/892f1793-bbef-4399-9aed-3c8d83883dc7.png?x-oss-process=style%2Farticle-content)、[测试界面截图](https://oss.mojidict.com/article/images/43337fe0-242b-43cf-93f4-811e785d6109.jpeg?x-oss-process=style%2Farticle-content)，均来自MOJi官方文章。截图用于了解界面，产品中使用自己的组件和数据。未登录实际手机App逐屏体验，因此当前版本的像素、动画和全部边界行为尚未核实。

## 本项目的页面方案

| 页面 | 呈现内容 | 实现边界 |
| --- | --- | --- |
| 背词首页 | 词书封面、词书名、总词数、已学数；显著的开始复习入口；新词数、待复习数和继续上次训练 | 数量来自实际学习身份，跨本统计按UUID去重；无每日配额或固定完成天数 |
| 单词本详情 | 紧凑词条行、假名、主要释义、发音、下一次复习提示；全部/未学习/待复习/学习中/耳词筛选 | 个人有效内容优先，未覆盖部分继承基准；无发音和封禁状态明确显示 |
| 测试卡片 | 顶部词书和进度、中间听音按钮、点击显示答案、下方三种评分；例句和笔记进入详情区域 | 第一版是听音回忆；不提前露出单词和释义；每组最多10词，Again自动到本组剩余队尾 |
| 听词播放器 | 单独的耳词播放入口，卡片/列表、暂停继续、上一词/下一词、循环、间隔、遮挡 | 后续实现耳词轮播；浏览播放不冒充完整复习，例句默认不自动播放；额外测试完成才更新FSRS |
| 词书管理 | 新建和编辑弹窗，更多菜单中的重置、删除；学习主界面以开始和继续为主要操作 | 重置仍清除范围内全部共享进度及手动重点；最后关联删除仍按既有规则彻底清理 |

配色方案采用白色/浅灰背景和红色主要操作；词书封面使用项目自己的图形与文字。训练区在手机上突出大卡片和底部评分，桌面端保留阅读宽度。颜色、文字和操作均兼顾键盘及读屏访问，评分不只依赖颜色。

## 保留的学习规则

1. FSRS继续决定实际到期时间，到期词优先于新词，未到期词只在额外训练中加入。新学、复习可以分开查看，默认开始入口仍按到期优先生成批次。
2. 第一版只提供听音回忆，题型协议仍预留扩展。以后多题型时，每组词先完成一种题型再进入下一种，所有题型通过才完成该词，取全部尝试中的最差评分。
3. 每次判定原子写入所属账号缓存，每词完成立即尝试上传；只有服务器确认后清理过程记录，保留手动补传入口。
4. 同词跨单词本共享进度，私人词条与公开词条仍保持独立身份，未来归并使用单独的迁移流程。
5. 播放失败和无发音不能静默当作完成；云音频尚未配置时保留真实提示。
6. 已学统计指完成过复习的唯一词数。“已掌握”的判定阈值尚未确认，当前不引入100分或永久移出复习的状态。

## 当前代码对应关系

- `frontend/src/pages/LearningPage.vue`：现有单词本、创建表单、同步提示、管理操作和词条列表集中在一页。改版将学习总览与当前词书内容分开呈现，管理入口使用弹窗或菜单。
- `frontend/src/pages/TrainingPage.vue`：现有听音、隐藏/显示答案、评分与队尾重试已实现；主要调整卡片布局、进度显示和评分操作区，不改变提交事务。
- `frontend/src/core/training.ts`：已有分组、题型协议、重试队列及完成状态。界面改版继续复用此状态机，避免重新实现一份评分或调度逻辑。
- `frontend/src/platform/web`：离线准备、资源版本、草稿恢复及多账号进度继续沿用。

建议实施顺序：背词首页与单词本列表 → 听音测试卡片 → 独立耳词播放器 → 后续题型与统计扩展。

交互草图：[MOJi参考背词交互草图](./MOJi参考背词交互草图.html)。使用示例数据演示总览、筛选及下文题型，尚未连接API、音频或真实学习进度；草图自身不连接5174预览。题型展示脚本为同目录的`MOJi参考题型交互.js`，打开草图时保留两个文件在同一目录。

实际页面已完成第一步改版：`/learning`展示背词总览，`/learning?book=UUID`展示单词本内容，听音训练采用隐藏答案的大卡片。实现范围和验收见[背词界面改版与测试](./背词界面改版与测试.md)。其他题型仍在独立草图中预览，耳词播放器、列表的读音与释义摘要等后续项尚未完成。

## 补充调研：题型与呈现模式

继续依据官方说明书中“MOJi辞書APP端 → 背词设置 / 新学”部分，而非MOJiTest或其他语言产品。官方将选择、回忆、快速自测作为模式；具体题型还包含拼写。新学与复习可以分别配置，选择题使用四选一；回忆和快速自测依赖翻面。来源：[MOJi官方说明书](https://webpc-debugten.mojidict.com/support/)。

| 参考类别 | 官方列出的内容 | 本项目草图如何体验 |
| --- | --- | --- |
| 单词、假名与释义的对应 | 看单词选释义、看释义选单词、看假名选释义、看释义选假名、看单词选假名 | 四选一，判定后展示词条及例句 |
| 释义辨别 | 看单词选错义 | 显著提示“请选择不属于这个词的意思”；三个正确解释加一个不相关解释 |
| 听音选择 | 听发音选单词、听发音选释义 | 按模拟听音按钮后才能选答案；草图没有实际音频 |
| 拼写 | 看释义拼单词、看单词拼假名、拼写例句 | 输入作答、核对答案、错误后队尾重试 |
| 回忆与快速自测 | 翻面回忆自评；快速自测可选择显示字段并使用例句提示 | 听音回忆沿用第一版；快速自测先演示紧凑单词行遮挡释义、逐词翻面评分 |

官方更新说明也提及按词条特点组合题型，以及针对输入法优化拼写判定。例如纯假名词若把单词直接当读音题面，会暴露答案。官方并未公开完整的拼写容错算法。来源：[MOJi辞書7.2.0更新说明（2023-09-06）](https://www.mojidict.com/article/HUAB6onHCB)。

用户此前提出的“听音选假名”可以作为本项目未来扩展，但不把它写成上述辞书说明书已列出的题型。快速自测的字段切换、整组列表翻面，以及例句拼写的具体提示方式仍需后续设计；当前草图只提供部分呈现方式。

## 本项目的题型扩展提案

以下是本项目自己的方案及草图行为，不代表已经核实的MOJi实现，也不改变正式第一版仅听音回忆的范围。

1. 通过题型注册表描述稳定ID、作答方式、题面字段、答案字段与音频需求。选择、拼写、自评共享批次调度，但各自保留判定规则及协议版本。生产代码后续复用已有`training.ts`和`reviews.ts`，草图脚本只用于比较交互。
2. “题型体验”允许单独体验或按勾选顺序组合。“常见三种”演示单词选释义 → 单词拼假名 → 听音回忆。当前批次保留题型快照；修改勾选只影响下一次开始，不重置真实学习进度。
3. 每组最多10词，先让整组通过题型A，再进入B。Again自动加入当前题型队尾，包括最后一个错词；最后一种题型每词通过即完成该词，无需等待整组完成。全部尝试中的最差评分仍作为最终评分，重试成功不抹掉之前的Again。
4. 草图中的客观题：答错必须重试；答对可选“答对，继续”或“答对但困难”，分别演示Good和Hard。该映射尚属提案，不自动推广成正式评分规则。翻面自测沿用三档自评，单纯浏览不算完成。
5. 拼写草图先进行NFKC和首尾空白归一化，仅假名读音题接受对应片假名；整句允许省略末尾日文句号，其他内容仍严格匹配固定样例。输入法合成过程中的Enter不提交，空答案不记分。正式实现还应由词条有效内容列出合法写法，避免把未经审核的同义写法或任意罗马字当作正确答案。
6. 正式出题前检查适用性及资源。纯假名词避免题面泄露读音；多义、同音、同形、私人覆盖内容需保证题面明确且只有一个可选正确答案；选错义不能仅因某释义不在当前义项就判错。缺少足够可证实的正确释义时，不生成选错义题。缺少例句、读音或有效离线音频时，显示不可用原因，不能静默减少所选必答题型或算作完成。
7. 离线批次未来还需缓存题面、合法答案、干扰项、题型版本及所属账号，以便恢复同一题并避免内容更新影响判定。保存、逐词提交、补传和重置隔离继续使用已确认的协议。

草图只有3个常规样例词，额外训练含第4词；分组上限为10，但当前不模拟大词库的多组效果。暂停可保留本页内存中的输入和翻面状态，刷新或关闭网页不会恢复；生产应用的离线缓存不受影响。
