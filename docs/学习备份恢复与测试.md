## 使用方法

在“离线准备 → 学习数据备份”导出学习数据 JSON。需要恢复本机记录时，联网登录原账号，点击“恢复本机学习记录”并选择该文件。

预检显示可恢复的待上传答题和训练草稿，以及已上传、本机已有、已删除/重置、冲突和跳过草稿的数量。预检不写入数据；点击“确认恢复到本机”时会重新核对。服务器或本机的结论改变后要求重新预检，不沿用陈旧结果。

恢复后可点击“上传本账号待提交记录”，或在学习页使用既有补传功能。恢复本身不提交答题；只有服务器明确接收后才清理待上传事件，重复事件不再增加 FSRS 复习次数。该按钮按已有补传协议上传本账号所有待提交记录，不限于本次恢复文件。

## 当前恢复范围

- 支持当前 `application=language-lean`、`schemaVersion=1`、UTF-8 JSON 文件，最大 20 MB；接受联网或离线导出的文件，只读取其中明确支持的本机学习记录。
- 必须同一服务器地址及同一账号 UUID。账号同名重建、其他账号、不同服务器地址及已注销身份不能继承旧数据。
- 待上传事件保留原事件 ID、轮次 ID、基准版本、基准事件、实际答题时间及完整判定记录。时间戳版本字符串不重新格式化，避免破坏后端幂等正文校验。
- 已接收事件比较原提交正文后跳过；现有本机事件保留，不覆盖已有较新的学习状态。已删除学习身份及旧重置代次排除；事件冲突或明显未来时间异常排除，保留原文件便于核对。
- 基准事件缺失时保留原待上传记录并明确提示，不伪造基准或改变答题时间。需要补齐依赖事件后再上传；失败仍沿用现有冲突处理和重试流程。
- 恢复有效的分组、题型阶段、Again 队尾和未完成判定。已上传词从草稿确认关联中移除，其余词继续原队列；本机已有对应批次或同单词本训练时保留当前训练。删除的单词本、成员改变、词条封禁、内容/个人版本变化会使旧草稿跳过，有效的完成事件独立保留。
- 草稿内容从当前服务器重新读取，不直接信任备份里的词条正文、笔记、来源、链接或调度配置。只有当前基准一致时使用服务器 FSRS 配置；不导入文件中的进度投影、账号缓存、隔离标记和音频对象地址。
- 备份不含音频文件，继续训练时需要联网补齐当前音频。文件缺失或播放失败不能显示答案或评分。已缓存且匹配的音频仍可使用。

此入口用于设备或浏览器本机记录丢失后的补回。服务器备份部分目前作为保留资料，不通过该入口重建单词本、私人内容、已删除学习身份或覆写服务器 FSRS；跨账号/迁移服务器的完整恢复另行设计。历史备份不自动复活已明确删除或重置的数据。

## 实现边界

后端新增受 CSRF 保护的只读 `POST /api/v1/learning/recovery-check`，请求明确绑定认证账号；每组最多核对 200 个学习身份、200 个单词本和 200 个事件，客户端按组请求。JPA 使用一致数据库快照核对归属、当前重置代次及已接受事件；外账户事件只返回冲突，不能读取私人正文。无新增数据库表或迁移，既有初始化 SQL 保留。

前端只在预检通过、重新核对成功后，以一个 IndexedDB 事务补充缺失记录。空间不足、删除/注销隔离、缓存变化或写入失败整体回滚，不覆盖其他账号分区及现有队列。未知题型/版本、损坏队列、重复标识、非法时间戳和原型键拒绝导入。文件仅在浏览器内解析，不把完整备份上传到服务器。

服务器与浏览器之间不能形成跨数据库原子事务。核对之后发生的远端删除/重置仍由既有学习核对、上传时的归属/代次检查阻止恢复服务器进度；在线进入训练前再次核对。断网期间的缓存副本边界沿用现有离线设计。

## 验证

后端全量 112 项、前端 126 项测试及生产构建通过。新增后端测试覆盖只读行为、账号/事件隐私、CSRF、批量限制、已接收事件及删除/重置识别。前端使用真实训练与导出路径生成备份，覆盖原队列、重复恢复、已接收确认、版本文本保留、现有状态/多账号保护、非法格式、会话切换、不完整响应、确认前变化、存储失败回滚与重试。

独立 PostgreSQL、实际本地 SMTP 和 Chrome 验证实际 JSON 下载、清空本机后预检/恢复、Again 原队列、另一分区保留、恢复后上传只计一次、再次导入识别已上传、重置/删除跳过、跨账号拒绝及缺失音频阻止评分。390px 弹窗无页面溢出或运行时错误；验收未使用真实账号，也未调用云 TTS。

本地预览入口：[localhost:5174/offline](http://localhost:5174/offline)。真实云音频需要已配置的 Google/R2，恢复不会生成替代音频。

预览已升级，升级前完整数据库备份位于忽略目录。账号及学习表摘要升级前后完全一致，仍为 2 个账号及 208,684 条词典词条；登录页和 API 只读验收通过，未登录恢复请求被拒绝。独立测试容器和数据卷已清理。
