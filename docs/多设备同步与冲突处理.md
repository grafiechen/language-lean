# 多设备同步与冲突处理

同一账号在其他设备删除词条、移除单词本或重置进度后，本机联网进入单词本、离线准备或训练页面，以及上传进度前，会核对服务器状态。单词本页也提供“核对服务器学习状态”按钮。这是进入页面和上传时的核对，不是实时跨设备推送；断网期间仍使用本机已有快照。

## 实际行为

| 服务器变化 | 本机处理 |
| --- | --- |
| 只从 A 移除，B 仍引用相同学习条目 | 更新 A 的缓存关联，保留共享进度和已完成的待上传事件 |
| 删除最后一个关联 | 清理旧学习身份的待上传事件、状态及冲突提示；相关训练取消，离线范围需要重新准备 |
| 删除后重新加入 | 新学习条目使用新 UUID，旧事件不会挂到新身份上 |
| 任一单词本重置共享词条 | 按新 `progressEpoch` 撤销旧进度缓存，使引用该词的离线准备失效 |
| 公开版本变化或词条封禁 | 取消使用旧内容的训练，离线范围标为需要重新准备；未被确认的完成事件仍保留，由提交接口判定 |
| 核对失败、账号变化或响应不完整 | 保留本地数据，不据此认定词条已删除 |

取消训练以整个批次为单位，批次内尚未完成的判定需重新练习；其他已完成的有效待上传事件保留。已确认的服务器进度不会被丢弃操作修改。下载开始和结束使用本地缓存修订校验，期间发生删除或重置时，迟到的下载结果也不能把旧内容重新标为“已准备”。

## 处理上传冲突

单词本页的“需要处理的上传记录”显示未上传成功的词条和原因。冲突信息保存在当前账号的 IndexedDB 分区，刷新后仍可查看。

- “重试上传”使用原事件 ID、实际答题时间和基准版本补传全部待上传记录，不通过改时间或重新生成 ID 绕过冲突。一个词失败不阻止其他独立词上传。
- 基准记录不存在时，应先补传原基准；设备时间超前时，应先修正设备时间，再等待原完成时间符合服务器容差。
- 确认无法恢复后，可点击“丢弃未上传记录”。确认框明确说明会一起删除依赖这条事件的后续未上传记录，并取消相关未完成训练。其他词的独立事件、其他账号缓存和服务器已确认进度保留。
- 已明确核实为重置或最后关联删除的旧事件按用户既有删除/重置规则自动清理；未知错误、网络故障和普通版本冲突继续保留。

## 核对接口

`POST /api/v1/learning/reconcile` 需要登录及 CSRF 校验，仅读取数据：

```json
{
  "learningItemIds": ["学习条目 UUID"],
  "wordbookIds": ["单词本 UUID"]
}
```

两组字段都必填，各最多 200 个 ID，重复值规范化去重，空数组允许。响应包含 `userId`、`items`、`missingItemIds`、`books`、`missingBookIds`；`books` 中每项包含单词本摘要和完整当前成员 ID。仅返回登录用户自己的学习条目，其他账号的 ID 与不存在的 ID 都返回缺失，不暴露跨账号内容。单次查询使用只读重复读事务。

客户端超过上限时分批请求，收到全部结果后才执行一次本地事务。每批检查登录归属，以及存在/缺失两组是否无重复、完整覆盖请求集合。网络期间本机缓存修订或学习代际变化时重新核对，最多三次；不能用迟到响应覆盖本机新状态。

复习接口的业务错误返回 `{ "code": "错误码", "detail": "中文原因" }`：

| code | HTTP | 含义 |
| --- | --- | --- |
| LEARNING_ITEM_MISSING | 404 | 当前账号的学习身份不存在 |
| PROGRESS_RESET | 409 | 提交属于已失效的重置代际 |
| BASELINE_MISSING | 409 | 基准事件缺失或基准有歧义 |
| EVENT_CONFLICT | 409 | 同一事件 ID 的内容不一致 |
| ATTEMPT_CONFLICT | 409 | 相同完成轮次使用不同事件 ID |
| WORD_UNAVAILABLE | 409 | 词条当前不可用于学习 |
| CLOCK_SKEW | 400 | 答题时间超出服务器允许的领先范围 |

## 存储与验证

服务端本轮无需新增 SQL 迁移，沿用 Flyway V1–V10；词典初始化 SQL 继续保存在仓库。IndexedDB 升至 v4，保留原表，新增 `issues`（账号和事件的冲突原因）与 `syncMeta`（每账号本地缓存修订计数）。冲突表不复制完整学习内容，不保存密码、令牌或邮箱。

后端 45 项测试通过，前端 51 项测试、TypeScript 检查及生产构建通过。自动测试覆盖完整响应验证、200 条分批、账号隔离、事务回滚、网络失败、下载期间删除/重置、迟到核对响应和依赖链丢弃。

独立 PostgreSQL 浏览器验收使用两个浏览器会话模拟同一账号的两台设备，验证远程重置、共享关联移除、最后关联删除后重加、冲突刷新保留、独立词补传和明确丢弃依赖链。390px 页面无横向溢出，未发现运行时错误。云音频使用测试替身，真实 Google/R2 互通仍等待配置后的验收。
