# 个人内容覆盖与测试

在“我的单词本”点击词条名称，进入自己的学习内容详情（`/learning/items/{learningItemId}`）。个人释义、学习笔记和标签跨单词本共享同一学习身份；公开词典详情仍展示公开内容。公开条目的个人读音、完整词义与例句随后也已接入，结构版本和音频规则见[个人读音与例句覆盖测试](./个人读音与例句覆盖测试.md)。

## 编辑和展示规则

- 关闭“使用个人释义”：展示最新公开词义及例句。
- 开启“使用个人释义”：个人释义替换整组词义，不逐项覆盖公开词义；读音独立选择继承或个人覆盖。页面和训练答案明确标记个人释义。
- 笔记和标签只对本人可见，笔记按普通文本显示，不执行 HTML。
- 标签支持中英文逗号和换行，去空、保留顺序去重；最多20个，每个50字。释义最多4000字，笔记最多10000字。
- “清空个人内容”需确认，清除个人读音、词义、例句、简单释义、笔记和标签，重新沿用公开内容，保留学习进度。只关闭简单个人释义并保存则恢复公开释义，保留其他覆盖、笔记和标签。
- 个人编辑与清空不修改公开词典、不生成第二份进度，也不改 FSRS 状态、复习次数、完成事件或重置代际。

每次保存使用独立的个人内容版本。另一页面或设备已修改时返回409，旧表单不会覆盖；页面提供“重新加载内容”入口。清空后版本继续递增，不能被旧版本再次作为初次保存。

## 学习、离线和删除

训练准备读取本人有效内容，并固定为本轮快照；显示答案时使用个人释义、笔记和标签。公共 TTS 仍只接收公共发音文本，不包含私人正文。

联网准备单词本时保存有效内容到当前站点和账号的 IndexedDB 分区。没有发音的词也保存内容快照，可离线查看，但不能参加听音训练。离线详情只读，并明确提示为上次下载版本；旧缓存不伪造个人内容，需要重新准备才能获得新增字段。

本机保存或联网核对发现简单释义、笔记或标签版本变化时，将涉及该词的离线准备标记为需要更新。已开始的训练继续使用原快照；待上传事件、未确认 FSRS 投影及草稿保留，可以完成后补传。个人读音或完整词义/例句结构更新则撤销旧训练资源和草稿，但保留已完成待上传事件；重新准备后新批次使用新内容。公共词条被封禁时仍显示封禁状态和空有效内容，不以个人释义绕过训练限制；本人仍能查看、整理自己的笔记。

重置任意单词本的共享进度时，个人释义、笔记和标签保留。从一个单词本移除时保留另一本仍引用的内容；最后关联删除时，个人覆盖和修改审计元信息级联清除。重新加入使用新的学习身份，从版本零和未学习状态开始；公开词典及其他账号不受影响。

## API 和数据库

| 接口 | 作用 |
| --- | --- |
| `GET /api/v1/learning/items/{itemId}/content` | 返回本人有效词条与个人元信息 |
| `PUT /api/v1/learning/items/{itemId}/content` | 保存完整个人内容表单，要求认证、CSRF和内容基准 |

PUT 表单字段为 `expectedRevision`、`meaningOverride`、`notes`、`tags`。`meaningOverride: null` 表示沿用公开释义；非空释义不得为空白。归属来自服务器会话，不接收客户端用户 ID。其他账号的 UUID 返回404，管理员同样不能读取他人私有内容。

V11 迁移保存于 `backend/src/main/resources/db/migration/V11__personal_entry_overrides.sql`，启动时由 Flyway 执行。`personal_entry_override` 按学习身份保存内容及版本；`personal_entry_override_change` 只保存版本和时间审计，不复制私人正文。两表随学习身份及账号删除，重置进度不删除。读写采用 JPA，编辑持有学习条目行锁，并在同一事务中保存内容和审计。原 JMdict 初始化 SQL 保留，不需重新导入。IndexedDB 沿用 v5，无新增表或索引。
