# 单词本编辑

更新日期：2026-10-07。开发分支：`feature/wordbook-edit`。

进入单词本的学习列表，打开“管理单词本”并点击“编辑单词本信息”，修改名称及说明。名称最多100字符，说明最多500字符，同一账号内名称不能重复。取消不提交；需要联网登录所属账号才能保存。中途断网保留输入，不能把未确认修改当作已成功提交。

`PUT /api/v1/learning/wordbooks/{id}` 携带 `accountId`、`version`、`name` 和 `description`。账户身份仍从会话取得，请求账号不匹配返回409，其他用户的单词本返回404，写请求需要CSRF。JPA锁定所属单词本、核对编辑版本并检查名称唯一性，数据库唯一约束兜底。旧版本返回409，没有字段变化的请求不递增编辑版本或更新时间。

单词本摘要新增元信息编辑版本，沿用已有数据库字段，不需要SQL迁移。这不是复习事件的时间戳版本，不改变词条身份、分类关联、共享FSRS状态、历史、手动重点或训练队列。

版本冲突后表单保留输入，可读取服务器当前名称及说明，再明确选择“采用服务器内容”或“保留输入并采用最新基准”。选择只是更新表单基准，仍要点击保存才提交，不能自动覆盖另一设备的修改。保存后废弃旧列表请求，防止迟到列表把新名称改回去。切换账号或离开页面关闭编辑器，旧账号响应不能写入新展示。

已有离线准备只更新本账号的名称、说明、更新时间及元信息版本，保留原准备状态、成员数量、词条、音频和准备时间，不创建虚假的离线准备。更新在IndexedDB事务中完成并递增缓存修订，较旧版本不能回写，已注销账号不能恢复。学习草稿、待上传记录及进度表不修改。服务器保存成功而本机更新失败时明确提示，并保持服务器已保存结论。

后端完整151项、前端完整139项测试及正式容器构建通过。新增检查覆盖归属、CSRF、旧版本、重复名称、空名称、无变更保存、共享学习状态、缓存账号隔离、迟到响应、已注销账号及草稿保护。独立PostgreSQL17和Chrome通过实际改名、离线名称更新、另一设备修改后的冲突、输入保留与明确重新提交、跨本同一学习身份及390px无溢出验证。
