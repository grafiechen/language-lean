# 系统用量与运维

更新日期：2026-10-06。

按项目实施顺序，账号、词典、学习及离线同步之后继续建设管理员用量和运维功能。当前已完成系统用量页，开发分支为 `feature/system-usage`。本功能没有合入生产 main，没有更新生产环境或调用真实 Google/R2/SMTP。个人学习数据导出按最新决定保持关闭；服务器运维备份与个人导出是不同边界。

## 后台入口和接口

`/admin` → “系统用量”。`GET /api/v1/admin/system/usage?month=YYYY-MM` 只允许 ADMIN，响应 `Cache-Control: no-store`。月份可选1970年起至当前UTC月份，留空使用服务端当前UTC月份。页面提供月份选择、刷新、加载和错误提示，离开时失效旧请求、清除旧快照，返回时重新读取。

统计只读取JPA汇总投影，不读取用户的私人词条、笔记、答题记录或账号标识明细。展示启用/停用账号、公开/未发布/封禁词条、数据库登记的音频资源与版本、未到期生成租约、生成失败资源、待清理云文件、待审投稿及待处理发音反馈数量。公开词条仍有编辑草稿时计入公开词条，不计入未发布词条。已有旧版本和生成失败可能同时存在，不能把资源计数作为互斥分类，不能把数据库登记数量当作实际可播放文件数。

运行配置仅显示Google调用开关、R2配置齐备状态、账号邮件和邮件密码重置状态、Secure会话Cookie及是否配置持久服务器主密钥。它们不证明外部服务已连通，打开或刷新页面不会发送邮件、连接云存储或调用TTS，也不显示主机、邮箱、密码、密钥及对象键。

## 音频用量记录

Flyway V21新增 `audio_generation_usage`。每次拿到生成租约和并发容量后，在调用合成适配器之前提交匿名用量开始记录。记录只有随机统计ID、服务器时间、服务商/模型、Unicode码点数、返回音频字节数及结果，不保存用户、词条、资源ID、发音正文、对象键或凭据，不随用户注销清除匿名历史。

可复用音频、缺少发音、语言关闭、未配置服务商、其他任务持有租约或无并发容量时，不创建合成用量。强制重生成及失败重试每次独立计数。统计是应用层的合成尝试，不保证服务商接到请求；例如加载凭据失败也可能发生在适配器内，因此不能推算付费调用次数或账单。

用量按开始时间归属UTC自然月，采用月初包含、下月月初不包含的区间。跨月完成仍计入开始月份，字符和字节采用累积计数，历史未接入统计的音频不倒推补录。最早记录时间是第一条保留的开始记录，不是系统安装时间。

结果分为：

- `READY`：生成、上传和可用音频版本切换成功。
- `FAILED`：合成或上传失败；云返回音频但上传失败时仍记录返回字节。
- `DISCARDED`：内容/配置已变化，或生成任务被新的任务替代，不切换过时版本。
- `REQUESTED`：开始已记录但最终结果未确认，可能仍执行或遇到进程中断/统计写入失败；不虚报为运行中或已成功。

统计开始写入失败会阻止进入可能收费的调用并释放生成认领，之后可以重试。最终统计写入失败则保留未确认状态，不影响已经成功生成的音频。记录采用独立短事务，不在调用外部服务时持有数据库事务。尚未设定计费、额度和统计保留期限，界面不编造价格或阈值。

## 验证结果

后端完整134项测试、前端完整135项测试及两端正式Docker镜像构建通过。用量测试覆盖缓存复用、并发去重、合成失败、上传失败、重试、内容变化弃用、Unicode码点、UTC月末半开区间及跨月完成、未确认状态、统计写入失败隔离、管理员权限、非法月份、配置脱敏和查询不调用云服务。

独立临时PostgreSQL17执行V21成功。Chrome真实页面登录及用量筛选通过：1999-06匿名测试数据展示2次请求、7个字符、1次返回、200字节、1次成功和1次失败，页面390px无横向溢出，非法月份返回400，旧个人导出接口仍返回404。临时数据库、容器及浏览器不使用现有学习数据。
