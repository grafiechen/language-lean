# 母语译文与例句导入

2026-10-04 用户确认：母语只决定释义和例句译文；词条及例句的发音保持学习语言。日语使用日语音频，英语使用英语音频。

## 使用

首页“母语与译文”选择语言并保存。偏好属于账号，在线修改后在同一账号其他设备登录可读取；浏览器按服务器与账号分别缓存偏好，离线沿用已保存设置。更改母语不改变学习词条ID、复习次数、FSRS或音频版本。

释义和例句译文优先按语言标签精确选择。来源没有该母语译文时，显示原译文及其语言，不将英文标为中文，不调用额外译文TTS。旧JMdict快照的释义确定为英语；未标注的个人历史文本显示“未标注语言”。

## 可演进内容契约

保留schemaVersion=1和原有字段，通过可选字段兼容旧快照及旧导入文件：

- 词义增加`glossLanguage`和`translations`。
- 例句增加`translationLanguage`、`translations`及独立`attribution`。
- `translations`按BCP 47语言标签保存`text/sourceName/license/sourceUrl/author`，最多16种。
- 例句出处记录来源、许可、HTTPS链接、源句子ID和可选作者；未知作者不编造。
- 管理员和个人内容编辑器均可增删译文，投稿、发布历史、离线快照保留这些字段。

外部新增译文不会自动成为已发布内容，继续经过现有草稿/审核。SUPPLEMENT只追加没有的译文语言；更改已发布译文用REVISION审核。

## 官方例句补充

采用[EDRDG的JMdict例句版](https://www.edrdg.org/wiki/JMdict-EDICT_Dictionary_Project.html)，其中例句在词义内已有官方关联，来源为[Tatoeba/Tanaka Corpus](https://www.edrdg.org/wiki/Tanaka_Corpus.html)。只使用更新后的精选子集，不使用早期未经纠错的原始语料。

生成工具`tools/jmdict_examples.py`按JMdict稳定ID和原词义核对，选择日语4至100字、英语最多400字、每词义最多3条的短例句，剔除损坏字符、缺少出处和重复句子。此规则保证长度及来源，不代表全部句子已由本项目人工校对。

```bash
bash tools/download_tatoeba_examples.sh
python3 tools/jmdict_examples.py data/jmdict/source/JMdict_b.gz \
  data/jmdict/source/JMdict_e_examp.gz data/jmdict/generated/jmdict-examples.sql.gz \
  --manifest data/jmdict/generated/jmdict-examples.manifest.json \
  --metadata data/tatoeba/generated/example-metadata.json
```

初始化时先完成Flyway（至少V16），执行`jmdict-initial.sql.gz`，再执行`jmdict-examples.sql.gz`。补充SQL仅对内容仍与原始快照完全一致、已发布、开源且无草稿的词条追加发布版本。人工编辑、封禁和不一致内容跳过，旧版本保持不变，重复执行不再次追加，学习数据不参与此事务。

词典许可和例句许可分别标注。`tools/tatoeba_example_metadata.py`从官方每周元数据核对日英句子正文及关联，保留作者，并按日语到中文的直接翻译关系补充中文；不把经英语中转的句子当成直接对应。未标注简繁的源译文保存为`zh`，可用于简繁母语展示，保持原字形，不擅自转换。例句缺少中文时显示有出处的英语译文。
