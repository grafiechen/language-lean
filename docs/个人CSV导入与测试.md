# 个人CSV导入与测试

## 使用

打开背词总览中的单词本，点击“导入个人CSV”。下载模板，选择UTF-8文件及文件中释义、例句译文的语言，再点击“预检CSV”。核对逐行报告后点击“确认导入有效词条”。第一版为日语词条，每批最多2MB、1000条；导入需要联网并登录本人账号。

列顺序固定，支持下列表头或无表头文件。前3列不可省略；假名允许空白，后4列可以省略。

```csv
written,reading,gloss,tags,example,exampleReading,exampleTranslation
該当,がいとう,符合,N2|工作,この条件に該当します。,この条件に該当します。,符合这个条件。
```

支持UTF-8 BOM、CRLF、双引号、字段内逗号及引号内换行。包含双引号的字段使用两个双引号转义。标签用`|`分隔，最多20个、每个50字。例句发音留空则不生成例句音频，不用正文补充未填写的发音。

## 导入边界

- 预检不创建内容、关联或学习进度。坏编码、未闭合引号等文件结构问题拒绝整个文件；业务字段错误逐行报告，确认时跳过错误行。
- 文件内按NFKC规范化写法去重，明确提示已存在。同一文件中的后续重复行跳过。
- 同一写法优先复用本人已有私人词条，再精确查找公开基准身份，不使用模糊或假名搜索猜测身份。
- 本单词本已有的词条跳过，其他单词本已有的学习身份只增加分类关联，保留正文、标签、笔记及FSRS。本人已有但尚未加入单词本的私人词条也只增加关联。
- 全新公开引用把CSV释义、读音和例句存为个人覆盖，不改基准词典。未找到基准身份时创建私有词条。释义和译文记录选定语言，发音保持日语。
- 确认核对文件及语言哈希，并重新检查当前数据库状态；预检后新增的私人内容不被文件覆盖。写入在一个JPA事务中原子提交，失败时整体回滚。重复确认不重复创建身份或重置进度。
- 新成员使本单词本原有离线准备标记为部分完成，保留原音频和未上传记录；需重新下载新增内容。已开始的训练继续原固定范围，新词参加后续训练。

接口为`POST /api/v1/learning/wordbooks/{bookId}/csv/preview`和`/confirm`，multipart字段为`file`、`translationLanguage`，确认另外提供`fileHash`。归属取认证会话，所有个人查询均按用户范围。

## 验证

解析测试覆盖BOM、逗号、多行、物理行号、引号转义、坏编码和数量限制。业务集成测试覆盖预检无写入、同文件重复、重复确认、跨本共享FSRS、本人内容不被覆盖、公开词典不变、译文语言保留、并发新增后复用和外账户拒绝。浏览器验收使用隔离PostgreSQL，验证模板下载、预检报告、确认、重复提示和小屏显示；云音频不参与CSV验收。
