# 私有词条与个人音频

2026-10-03 接入独立私有词条、本人音频和既有学习流程。个人词条不进入基准词典；公开贡献及审核仍为后续功能。

## 实际使用

1. 登录后从首页或“我的单词本”进入“我的私有词条”。页面使用列表，点击“新增私有词条”打开弹窗。
2. 可以先只填写法，之后补充读音、发音文本、释义和例句。内容来源读取后台维护的启用选项；内容许可保留说明。编辑时语言和书写系统固定，词条 UUID 不变。
3. 同一账号、语言、书写系统的写法经 NFKC 规范化后重复，提示“私有词条已存在，请使用现有词条”。同名公开词条及其他账号的私有词条允许存在，身份和进度各自独立。
4. 选择单词本后加入。加入 A、B 两本使用同一学习身份和进度；可在学习详情编辑个人释义、笔记和标签。
5. 有显式发音文本时可参加听音训练。缺少发音的词保留在单词本，并计入无法参与听音的数量。保存、打开详情及点击发音会检查音频，后台配置允许时补生成。
6. 在“离线准备”下载单词本，然后断网学习。Again 自动进入队尾；每次判定原子缓存，完成后产生一条复习事件。重新登录原账号后自动或手动补传。

其他用户及管理员不能通过私有词条 UUID 读取、生成音频或删除他人的私人内容。私人正文、音频按站点和账号分区缓存，不进入公共 Service Worker 缓存。

## 编辑、重置和删除

保存携带编辑版本，旧表单收到冲突时保留填写内容，可以点击“重新加载词条”读取新版本。创建表单通过 `X-Learning-Account` 指定预期账号，服务器与当前会话核对，避免另一标签页切换账号后错误归属。

私有词条的写法、读音、释义或例句版本变化时，联网核对会撤销该词关联的旧训练草稿及资源，使未来下载需要更新；已经完成的待上传复习事件保留。个人覆盖层的释义、笔记和标签修改继续沿用既有规则，保留已开始训练的固定答案。

重置某本会重置该本包含词在所有单词本中的共享进度，包括手动重点；词条正文和学习笔记保留。从 A 移除时若 B 仍引用，保留身份、正文和进度；最后一个关联移除时彻底删除私人词条、覆盖内容、进度、审计及音频元数据。列表中的“彻底删除”会直接清除所有单词本关联。重新创建或加入不会恢复原学习身份与进度。

客户端在一次 IndexedDB 事务中移除对应的训练草稿、事件、投影、离线词条正文、笔记及词条/例句音频。公共音频和其他账号缓存不受影响。服务器删除成功但本机清理失败时，页面分别提示结果；联网核对会继续处理服务器已删除的身份。

## 个人 TTS 配置和清理

“后台词典管理 → TTS 配置 → 允许个人音频生成”控制保存、详情、点击及手动重新生成。关闭后不发起新的个人生成，已有内容匹配的可用音频仍可播放。没有显式发音文本的词条或例句跳过生成，不以写法或正文代替发音。

个人资源使用 `PERSONAL` 作用域和 `audio/personal/` 对象路径。每次读取重新验证所属账号。生成复用数据库行锁、唯一资源、租约和获取锁后检查版本的流程；保存后在事务提交成功时进入有界后台生成队列。完成上传时再次校验源内容及个人生成开关。

删除时在同一数据库事务保存待清理对象键，立即撤销 API 访问，随后后台每分钟最多处理16个对象。云端删除失败会保留任务重试，不恢复词条。生成期间词条被删除，迟到上传的对象同样登记清理。清理表只保存对象键和时间，不保留私人正文或账号归属。现存词条的历史音频版本继续保留；公开音频的一般保留周期及孤立对象扫描尚未实现。

## API 和保存的 SQL

| 接口 | 作用 |
| --- | --- |
| `GET /api/v1/learning/private-entries?q=&page=` | 本人写法查询，每页20条 |
| `GET /api/v1/learning/private-entries/{id}` | 本人详情及编辑版本 |
| `POST /api/v1/learning/private-entries` | 创建，需要 CSRF 及预期账号请求头 |
| `PUT /api/v1/learning/private-entries/{id}` | 按版本修改写法和完整正文 |
| `DELETE /api/v1/learning/private-entries/{id}` | 彻底删除，返回被删除的学习身份 |
| `POST /api/v1/learning/wordbooks/{bookId}/private-entries/{id}` | 加入分类，共享学习身份 |
| `DELETE /api/v1/learning/wordbooks/{bookId}/items/{itemId}` | 移除一个分类关联，公私词条通用 |
| `GET /api/v1/system-dictionaries/CONTENT_SOURCE` | 登录用户读取启用的内容来源选项 |

音频入口沿用 `/api/v1/audio/entries/{id}/resources/{resourceId}/ensure`，个人请求带 `scope=PERSONAL`。本人可调用同路径的 `/regenerate`；公开音频的强制生成仍走管理员接口。

V12 迁移保存在 `backend/src/main/resources/db/migration/V12__private_entries.sql`，增加私有词条、修改审计元信息、个人音频归属及对象清理任务。JPA 使用本人归属查询、外键级联和编辑行锁。数据库、类和关键方法已补充中文注释。保留 V1–V11 和 JMdict 初始 SQL，不需重新导入词典。IndexedDB 沿用 v5，没有新增表或升级时清空数据。

H2 测试使用 V10 的专用副本，唯一差异是显式命名该版本的音频作用域约束，便于 V12 按名替换；实际 PostgreSQL 仍执行原始 V10 和 V12。
