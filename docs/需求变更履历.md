## 当前有效规则摘要

~~~text
基准词条 = 固定书写形式
词条内容 = 多读音 + 多词义 + 例句 + 语法信息
用户进度 = 每个用户、每个词条一份 FSRS/DSR 状态
用户贡献 = 个人实体独立，申请审核通过且公开后录入基准词典
个人覆盖 = 可修改自己的学习内容，不改公开基准
公开版本 = 线性历史，审核前旧版、发布后新版
离线学习 = 第一版必须支持，实际答题时间决定最新进度
上传粒度 = 词条所选类型全部完成后立即上传，支持今日手动补传
题型范围 = 第一版仅听音回忆，未来多类型逐项评分取最差，仅更新一次 FSRS
题型扩展 = 第一版就建立适配器和统一轮次协议，后续题型复用进度与同步流程
队列 = 到期优先，不设每日配额，第一版也分组穿插重试，额外训练更新 FSRS
删除 = 个人数据彻底删除，最后一个单词本移除才清除共享进度
重置 = 范围内全部共享进度及自动/手动耳词标记清零，其他单词本的同词同步归零
重复判断 = 固定写法，不看释义和标签
例句播放 = 点击播放，不自动播放
AI Agent = 未来功能，当前不设计
~~~
