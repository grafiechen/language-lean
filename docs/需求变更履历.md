## 当前有效规则摘要

~~~text
基准词条 = 固定书写形式
词条内容 = 多读音 + 多词义 + 例句 + 语法信息
用户进度 = 每个用户、每个词条一份 FSRS/DSR 状态
用户贡献 = 可共享，但默认待审核
重复判断 = 固定写法，不看释义和标签
例句播放 = 点击播放，不自动播放
AI Agent = 未来功能，当前不设计
~~~
