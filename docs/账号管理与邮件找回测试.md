# 账号管理与邮件找回

> 2026-10-06 更新：密码和重置凭证请求使用后台签发的会话绑定、两分钟有效、只能消费一次的 AES-256-GCM 密钥；数据库仅保存经过服务器主密钥加密的临时密钥。个人学习备份导出按最新决定暂时关闭，既有备份恢复保留。此前描述的导出交付记录属于历史状态，详见[密码传输加密与测试](./密码传输加密与测试.md)。

更新日期：2026-10-05。

后台 `/admin` 的“账号管理”提供分页列表、用户名/邮箱搜索、状态筛选和新增弹窗。用户名与邮箱均必填，两者在所有登录标识中大小写不敏感且唯一。新账号默认普通用户，可明确勾选管理员；初始密码不显示在后台，而是发送到账号邮箱。数据库使用 JPA，账号只存带随机盐的 BCrypt 哈希。

启用/禁用携带账号编辑版本；旧版本提交返回冲突。不能禁用当前管理员，必须保留一个启用的管理员。状态变更和创建写入独立审计，只保留操作人 ID、目标 ID、动作和服务器时间，不记录密码、邮件正文或个人学习内容。禁用保留学习数据；账号注销和跨域数据彻底删除尚未交付。

每次受保护的在线请求回查账号。密码或启用状态变更递增 `security_version`，旧会话永久失效，重新启用也不能复用旧会话。登录态改密仅刷新当前会话，其他设备重新登录；找回密码使所有旧会话失效。母语设置不会让会话失效。服务器拒绝在线访问不会删除浏览器的离线内容或待同步记录。

登录页“忘记密码？”使用用户名或注册邮箱申请重置链接，有效 30 分钟且只能使用一次。256 位随机令牌通过 URL fragment 交给页面，不出现在服务器访问 URL；数据库仅存 SHA-256 摘要和签发凭据的摘要。重置提交受 CSRF 保护，账号锁保证并发请求只有一次成功。密码/状态变更使之前的链接失效，重新申请会替换旧链接。申请接口对未知、禁用、限流和邮件失败返回相同提示；同账号一分钟最多一封，同 IP 十分钟最多十次申请。第一版 IP 限流使用有界内存，适用于单应用实例；同账号发送限制由数据库维护。

密码沿用至少 8 位且包含字母、数字、特殊字符的规则。BCrypt 输入最多 72 个 UTF-8 字节，超出在业务校验时拒绝，避免编码器异常。系统生成的初始密码为随机 16 位。

## 邮件配置

把 `.env.example` 的以下项填入本地 `.env` 或部署环境，禁止提交真实凭据：

| 配置 | 用途 |
| --- | --- |
| `MAIL_ENABLED` | 默认 false，配置好再开启 |
| `MAIL_HOST` / `MAIL_PORT` | SMTP 主机和端口，默认 587 |
| `MAIL_USERNAME` / `MAIL_PASSWORD` | 邮件服务登录凭据 |
| `MAIL_FROM` | 发件邮箱 |
| `MAIL_STARTTLS` / `MAIL_SSL` | 587 通常用 STARTTLS；465 通常 SSL=true、STARTTLS=false，两者不可同时开启 |
| `PUBLIC_APP_URL` | 实际访问的站点根地址；生产使用 HTTPS，本地允许 localhost / 127.0.0.1 的 HTTP |

后台只返回邮件就绪状态，不返回 SMTP 凭据。初始密码发送失败会回滚账号、登录标识与审计。找回邮件失败会回滚重置凭据。同步发送中的 SMTP 接受与数据库提交无法成为分布式原子事务；SMTP 超时不能保证邮件一定未被接收，失败提示后应先检查邮箱与列表，再重新操作。

## 本地测试收件箱

`compose.mail-dev.yml` 使用 Mailpit 接收本地邮件，不向外部邮箱投递，SMTP 只在容器网络中开放，收件箱 UI 仅绑定本机。在 PowerShell 中运行：

```powershell
wsl -d Ubuntu -- bash -lc 'cd /mnt/d/gitHome/language-lean && docker compose -f compose.yml -f compose.mail-dev.yml up -d'
```

浏览器打开 `http://localhost:8027` 查看初始密码或重置链接，可用 `MAILBOX_PORT` 修改收件箱端口。覆盖文件默认站点地址为 `http://localhost:5174`；端口变化时设置 `PUBLIC_APP_URL`。热更新模式将基础文件换成 `compose.dev.yml`，并设置 `PUBLIC_APP_URL=http://localhost:5173`。恢复外部 SMTP 使用基础 Compose 和 `.env` 配置重新创建 API，避免继续带本地覆盖文件。

## 实际验收

1. 管理员打开账号列表，用“新增账号”弹窗创建测试账号；邮箱可用 `learner@example.test`，在本地收件箱读初始密码。
2. 验证用户名和邮箱都能登录，普通用户不能访问后台；大小写重复或把已有邮箱当新用户名，应提示已存在。
3. 两个浏览器登录同一测试账号；一个修改密码后当前会话继续可用，另一个在线请求要求重新登录。
4. 管理员禁用测试账号，验证原会话和新登录都被拒绝；重新启用后使用新会话登录，旧会话仍不能使用。
5. 登录页申请重置链接，从本地收件箱打开、设置新密码。使用旧密码登录失败，重复提交同一链接失败；不完整链接、过期链接和密码/状态变更前的链接均失败。
6. 浏览器 390px 检查新增弹窗和找回页面。列表可横向滚动，页面不溢出；链接读取后地址栏移除令牌。

迁移 `V17__account_administration.sql` 随应用启动由 Flyway 执行，包含中文表/字段注释；现有初始账号和词典导入 SQL 不需要修改。
