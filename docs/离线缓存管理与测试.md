# 离线缓存管理与测试

在“离线准备”（`/offline`）的“本机缓存”区域查看用量、清理下载或申请浏览器保留离线数据。断网以及服务器暂时不可用时，仍可读取和管理本机缓存。

## 用量口径

- “本站占用 / 浏览器额度”来自浏览器估算，包含同一站点的所有账号、IndexedDB 和静态应用页面；不支持或读取失败时显示“无法估算”。
- 当前账号的音频大小按实际 Blob 字节统计；词条与训练快照按 JSON 的 UTF-8 字节估算，不代表 IndexedDB 的实际磁盘占用。
- 单独展示离线范围、待上传记录、冲突及未完成训练，并提供继续训练入口。切换账号时清除上一账号的显示，迟到统计不得覆盖新账号。

浏览器额度和占用不是固定数值，参见 [StorageManager.estimate](https://developer.mozilla.org/en-US/docs/Web/API/StorageManager/estimate)。

## 清理边界

| 操作 | 删除内容 | 保留内容 |
| --- | --- | --- |
| 清理未引用音频 | 当前账号没有被任何离线准备或训练快照引用的音频 | 所有学习记录和仍被引用的音频 |
| 移除单词本的本机下载 | 该本的离线准备快照及由此不再被引用的音频 | 其他单词本下载、共享音频及学习记录 |
| 清理当前账号下载 | 当前账号所有离线准备快照及未引用音频 | 其他账号、待上传记录、冲突、训练草稿、未确认 FSRS 投影和服务器内容 |

移除单词本或当前账号的下载需确认。这些操作不会删除服务器单词本、移除服务器词条或重置学习进度。

进行中的训练和已完成但未确认上传的训练快照继续引用音频，因此清理当前账号下载后，音频用量可能不为零。可通过“继续未完成训练”完成原队列，重新登录原账号并补传；服务器确认后，训练快照撤销引用，再清理未引用音频。只有待上传记录而没有离线准备的账号仍可在本机选择。

清理在一次 IndexedDB 事务中重算引用、删除下载并更新缓存修订；失败整体回滚。正在下载的旧结果和已准备但尚未开始的旧批次必须核对修订，不能恢复已清理的下载。已开始的队列保留，可以继续判定。缓存按站点和账号 UUID 隔离，相同音频版本也不会清除另一账号的文件。

## 存储不足与浏览器保留

遇到 `QuotaExceededError` 时，训练和离线准备显示空间不足提示，并提供缓存管理入口。判定、完成事件和未确认投影仍原子写入；写入失败不会将未保存的判定计入复习，不会静默丢弃待上传记录来腾空间。

“申请保留离线数据”仅在点击时调用浏览器的 `persist()`，不会自动请求。浏览器可以同意或拒绝，拒绝不删除已有数据；不支持此能力时禁用按钮。HTTPS 或 localhost 上的支持情况由浏览器决定，主动清除浏览器数据仍会删除缓存。参见 [StorageManager.persist](https://developer.mozilla.org/en-US/docs/Web/API/StorageManager/persist)。
