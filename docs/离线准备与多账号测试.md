# 离线准备与多账号缓存

本轮支持先联网准备单词本，随后断网关闭页面，再重新打开继续学习。首次访问必须联网，未下载的词条和音频不能凭空离线使用。Google/R2 配置仍按《音频配置与听音训练》保留，默认关闭云调用，配置后才能下载真实发音。

## 实际使用

1. 登录，创建单词本并加入词条。
2. 首页或单词本页打开“离线准备”，对需要的单词本点击“准备离线内容”。该入口准备整个单词本的听音回忆内容和主要可用发音，不受当前到期范围限制。
3. 等待“已准备”。应用页面、路由脚本、词条快照和训练音频都已保存。缺发音词单独计数，有发音但生成或下载失败则显示“部分失败”并列出原因；中途关闭保留准备中状态，联网后重新准备。
4. 断网重新打开 `http://localhost:5174/offline`，选择已缓存的账号，再进入听音训练。也可以直接重新打开上次的训练地址，恢复原分组和 Again 队列。
5. 登录过期时可用已有账号缓存继续学习。联网后点击“登录后同步”，登录学习记录所属账号，在单词本页补传进度。服务器已登录其他账号时不会发送旧账号的记录。

日队列按服务端确认时间或本地 FSRS 预估时间过滤。已完整准备参数的离线词完成后，按本地周期重新纳入到期日队列，连续轮次引用前一条待上传事件，补传时先提交基准再提交后续。旧缓存缺少算法参数时不猜测周期，可先额外训练或联网重新准备。详见[离线 FSRS 调度与验证](./离线FSRS调度与验证.md)。

本地缓存选择只决定学习数据归属，不是服务端登录。离线模式不能打开后台管理、修改密码、创建或删除单词本、移除词条和重置进度。这些操作当前需要联网认证。公共词典全库离线浏览尚未实现，当前下载范围是已选择单词本的训练资源。

## 缓存结构与升级

IndexedDB `language-lean` 版本 5 保留已有 `pending`、`drafts`、`states`、`audio`、`resources`。版本 3 增加账号与准备快照，版本 4 增加冲突及缓存修订记录，版本 5 增加离线调度投影：

| 表 | 主键 | 内容 |
| --- | --- | --- |
| accounts | accountKey | 服务器来源、稳定用户 UUID、显示用户名及上次使用时间 |
| preparations | accountKey + wordbookId | 单词本摘要、学习身份、词条/音频版本、准备状态和失败原因 |
| issues | accountKey + eventId | 未解决上传冲突的原因，原事件仍保留在 pending |
| syncMeta | accountKey | 本地缓存修订计数，阻止迟到响应恢复旧状态 |
| projections | accountKey + eventId | 未确认事件的卡片计算结果与下次时间，与确认状态分开保存 |

账号缓存不保存密码、令牌、邮箱或管理员权限。当前归属使用站点来源与用户 UUID，不以用户名或邮箱合并。重装、清除站点数据、浏览器存储回收可能删除缓存，因此联网后应及时同步。显式退出保留各账号学习数据，但阻止刷新后自动恢复残留服务端会话；用户仍可明确选择离线账号，在线登录成功才解除退出抑制。

确认上传后清除事件及过程草稿，离线准备范围和音频仍保留供继续学习。单词本删除只撤销该本的缓存；另一单词本仍引用的共享进度保留。进度重置或最后引用删除会清除失效草稿和待上传记录，并将所有涉及该共享学习身份的离线准备标为失效，要求重新准备。

## 静态应用壳

Vite 构建插件根据产物内容生成 `sw.js`，预缓存无用户数据的入口及全部路由脚本和样式。Service Worker 不拦截 API、私有音频、写请求、外部域名或未列入清单的文件；个人资源只进入 IndexedDB 的账号分区。新应用版本等待旧页面关闭后启用，避免训练中途强制刷新。开发热更新不注册 worker，离线冷启动请使用生产式 Docker 预览。

浏览器要求正式部署使用 HTTPS，本机 localhost 可用于验证。说明依据：[MDN Service Worker 文档](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)、[Vite 插件 API](https://vite.dev/guide/api-plugin.html)。

## 验证与剩余范围

前端测试覆盖应用壳排除私人请求、会话过期与网络失败恢复、显式退出、多账号/来源隔离、旧数据库升级、准备不完整、音频缺失、待上传基准链、同时间戳比较、共享重置及删除分类。独立 PostgreSQL 浏览器测试使用两个真实账号，断网关闭页面后重新打开，完成并补传真实 FSRS 事件；云发音采用测试 MP3 替身，生产不会使用该替身。

联网进入学习页面或上传前已核对其他设备的删除、重置和成员变化；完整确认后撤销失效缓存，未知冲突保留并提供重试或明确丢弃入口。下载期间的删除/重置也阻止旧结果恢复为已准备。详见[多设备同步与冲突处理](./多设备同步与冲突处理.md)。核对不提供实时推送，断网时不能立即发现另一设备的变更。

离线调度已接入，包含固定参数、到期重入、连续轮次和确认后清理。缓存容量与清理管理已实现，见[离线缓存管理与测试](./离线缓存管理与测试.md)；更多个人内容功能仍待开发。
