# 账号注销与数据清理

更新日期：2026-10-05。

## 使用方式

本人联网登录后，在首页点击“注销我的账号”。弹窗要求当前密码及完整用户名，明确提示不可恢复；取消不会改变数据。管理员可在后台账号列表点击目标行的“删除”，输入管理员自己的密码和目标用户名。管理员不能在后台删除自己，应使用本人注销入口。

必须保留至少一个启用的管理员。删除使用固定的账号 UUID，并再次核对操作身份；后台同时校验列表中的目标版本，遇到修改或并发操作提示刷新重试。同名账号重建获得全新 UUID，旧删除请求及离线记录不能操作新账号。关闭公开注册的设置不变，重新创建仍由管理员完成。

## 清理范围

- 删除账号、用户名/邮箱登录标识、角色、密码哈希和重置链接凭据。
- 通过 ORM 删除账号并由外键级联清理单词本、关联、共享学习身份、FSRS 状态、耳词标记、复习历史、个人释义/笔记/标签、私人词条及私人修改历史。
- 删除该账号的投稿申请和私人快照。已经审核公开的正文、线性历史、外部来源及许可证保留；公开贡献元信息清除投稿账号关联并显示“已注销用户”。该显示目前采用建议默认值，未改变来源署名及许可。
- 删除私人及个人覆盖音频的资产/版本记录；捕获所有历史对象键，提交清理任务。公共音频及其他账号的内容、进度和缓存保留。
- 当前浏览器以服务器地址和账号 UUID 为分区，原子清理所有 IndexedDB 表中的对应记录，包括未上传事件、训练草稿、音频、下载快照、投影和缓存身份。保留无正文的分区隔离标记，拒绝迟到的下载和答题回写；不清空整个站点或其他账号的数据。

删除审计仅保留操作人 UUID、目标 UUID、动作及时间，不保存密码、邮箱、用户名或私人正文。数据库迁移 `V18__account_closure.sql` 保存中文字段注释；已经应用的 V17 保持原字节和校验值。初始化管理员只允许在空数据库创建，重启不能恢复已注销初始化身份。

## 网络和存储失败

数据库删除与云对象删除分开处理。云对象失败或暂未配置时保留仅含对象键的清理任务，由后台继续重试；业务身份和访问权限已删除，不能用失败任务恢复私人内容。生成途中注销时，尚未发布的新私人音频上传结果也进入清理队列。

服务器已删而本机缓存删除失败时，本人弹窗保留“重新清理本机缓存”入口，只重试本地清理。确认标记阻止离线恢复和迟到写入；其他设备的旧会话收到明确 `ACCOUNT_DELETED` 后也清理所属缓存。普通登录过期、禁用或网络错误保留离线学习记录，不推断账号已注销。若磁盘或浏览器存储权限始终不可用，需恢复存储后重试，或手动清理浏览器本站数据。

其他设备断网时无法远程删除其本机副本，注销说明明确告知这一边界。历史数据库备份、个人导出的文件和外部已传播的公开词条不由此接口改写；备份保留期限和恢复时处理注销记录的运维流程仍需后续确定，不能把在线库清理宣称为所有副本销毁。
