# 词条投稿与审核测试

更新日期：2026-10-03。当前完成投稿、审核及公开发布的闭环；尚未实现私有与公开学习身份的自动归并。

## 操作入口

本机预览为 http://localhost:5174。使用已有账号登录，首页进入“我的私有词条”或“我的投稿”。投稿和审核需要联网，不作为离线待上传的复习记录保存。

1. 在“我的私有词条”新增或编辑完整正文，至少有一条释义和内容来源；发音可留空。
2. 列表点击“提交审核”，核对读音、词义和例句，删除不希望公开的内容。表单不会自动附带笔记、标签或学习记录。
3. 勾选“申请审核通过后公开本次快照”，填写可选投稿说明并提交。投稿记录显示“待审核”，普通公开词典仍保持原样。
4. 管理员在“后台词典管理 → 贡献审核”查看提交快照和提交时的公开基准。当前允许管理员审核自己的申请，方便单人开发验收。
5. 通过审核并确认公开，或填写原因后拒绝。申请人可以查看原因，也可撤回仍待审的申请。
6. 已发布结果可从投稿详情进入公开词条；其贡献来源和许可单独显示。原私有词条和学习身份不会被切换或删除。

公开词条修订入口在“我的单词本 → 学习内容 → 提交公开修订”。先保存个人内容，再打开投稿表单；如果不需要个人覆盖，也可以直接在投稿表单中修改要提交的正文。

## 三种审核处理

| 类型 | 判定 | 通过后的行为 |
| --- | --- | --- |
| 新词条 | 私有写法在公开词典中不存在 | 建立新的全局公开UUID，来源类型为用户贡献，追加第一版历史 |
| 补充内容 | 私有写法与已有公开词条的语言、书写系统、规范化写法相同 | 保留公开原文及已有子项UUID，去重后追加新读音、词义和例句 |
| 内容修订 | 从已加入学习的公开词条明确提交 | 按提交时基准版本发布完整修订快照，历史序号递增 |

补充通过时，原基准词典的来源和许可保留，新增贡献的来源、许可另行写入公开历史，账号注销后也保留；公开页面显示最近20次已发布贡献。完全重复的补充不能制造新历史，申请仍保持待审，管理员可以拒绝并说明原因。读音、词性/释义以及例句正文/发音/译文分别规范化比较，包含全角空白去重。

后台有未发布草稿、目标词条封禁、语言禁用、审核期间公开基准已更新，都会阻止通过。管理员可以拒绝旧申请，申请人重新读取内容后再次提交。审核不能静默覆盖其他管理员已经发布的修改。

## 快照、并发与权限

- 申请正文和当时公开基准在提交时冻结；随后编辑私有正文或个人覆盖不改变申请。审核员不会读取来源的当前私人内容。
- 每个账号的同一来源最多有一份待审申请，终态后可以再提交。数据库唯一占位最终阻止并发重复。
- 相同请求UUID和正文的网络重试，包括同时发送，返回原申请；同一UUID换内容返回冲突。表单编辑后生成新UUID，失败重试保留原UUID。
- 创建时核对私有编辑版本，或个人覆盖版本和公开基准版本。审核、拒绝和撤回均带申请版本并加行锁，同时通过只生成一条历史。
- 普通用户只能读取自己的申请；他人详情返回404。审核接口需要ADMIN角色，所有写请求使用CSRF，并核对表单账号头，避免其他标签页切换登录账号后误提交。
- 公开贡献来源接口只返回已审核发布的来源、许可和版本，不返回申请人UUID、私人来源UUID或未审正文。封禁词条不返回贡献正文。

## 删除与学习边界

私有词条彻底删除时，未公开申请（待审、拒绝、撤回）正文同时清除；已经公开的申请与公开历史独立保留，私人外键置空。公开词条的学习修订申请只在该学习身份的最后单词本关联被移除时清除；仍在其他本中引用时保留。

审核发布不改变私人学习身份、FSRS进度、重置代际、笔记、标签及单词本关联。之后普通公开学习引用按既有内容核对流程更新公开快照。私人词条和同名公开词条仍各自存在；来源UUID和发布UUID已记录，后续身份合并及进度去重需要独立迁移流程，当前不自动执行。
