# 耳词训练与学习备份

## 耳词训练

在单词本的学习列表点击“耳词训练”。范围为该本的自动耳词及手动重点，包含未到期词，采用听音回忆题型。每组最多10词，Again排到组内剩余队列队尾。每词通过后只生成一个事件并更新一份FSRS，失败尝试保留在最终最差评分中。

准备时下载所有已填写发音的读音，普通训练仍使用主要读音。耳词按已完成次数及本轮重试次数轮换读音，切换读音不建立额外学习状态。缺少音频或播放失败不会允许评分，重新准备只修复当前读音。中途返回保留原模式和队列，切换入口仍继续原批次。

离线准备包含全部读音。缓存清理检查主要及轮换音频引用，不能误删轮换资源；旧缓存沿用主要读音，重新准备后支持全部读音。例句依然仅点击播放。

学习列表“更多”中可加入或取消手动重点，跨单词本共享。确认后立即更新本人同代次下载及训练快照的标记，立即断网也能进入耳词训练；不覆盖FSRS、复习次数或其他账号数据。取消手动重点不清除自动耳词；重置同时清除两者。

## JSON备份

入口为“离线准备”中的“导出学习数据JSON”。

- 联网且会话归属核对成功：服务器完整单词本、学习身份与FSRS状态、本人释义/读音/例句覆盖、全部私有词条、完整复习历史，再加本机未上传事件、草稿和离线快照。
- 离线：仅导出本账号本机已有数据，文件明确标注`includesServerData=false`，不冒充服务器完整备份。
- 本机多账号隔离，导出不含邮箱、用户名、密码、权限或会话信息。稳定账号UUID及来源服务器用于确认归属。
- 音频只导出版本与哈希元数据，不打包二进制，`includesAudioFiles=false`。服务器包含本人私人音频、本人覆盖及已引用的公开资源全部已保存版本；本机另含下载版本。排除管理员草稿、未引用公开音频、他人私人音频，以及云对象键、任务令牌和下载地址。导出不调用TTS或云存储。
- 导出不会上传、重置、删改进度或删除缓存；公开词条封禁后仍能备份自己的笔记。

备份使用`schemaVersion=1`。现已支持同服务器、同账号本机答题与草稿恢复，预检和确认时核对身份、代次、已上传事件及现有记录；删除/重置前的数据跳过，服务器内容和进度不由旧文件覆盖。备份不含音频，继续训练前需联网补齐；完整服务器及跨账号恢复后续设计。操作和验证见[学习备份恢复与测试](./学习备份恢复与测试.md)。
