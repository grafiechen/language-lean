已完成 FSRS 调度、完成事件提交、复习历史、训练草稿与待上传事件的原子持久化，以及手动补传入口。听音训练页面、服务端 TTS/R2 适配器和训练资源缓存已接入；配置真实云凭据后可以进行听音训练。离线准备和关闭后重新打开也已接入，配置与流程见[音频配置与听音训练](./音频配置与听音训练.md)和[离线准备与多账号缓存](./离线准备与多账号测试.md)。

## 调度和数据库

采用 [官方 Java FSRS](https://github.com/open-spaced-repetition/java-fsrs) `io.github.open-spaced-repetition:fsrs:1.0.0`，保存算法标识 `FSRS-6/java-fsrs-1.0.0`、完整卡片状态和每次使用的参数。默认目标保持率 0.9，最大间隔 36500 天，学习步骤 1/10 分钟、重新学习步骤 10 分钟，关闭随机间隔扰动。这是当前可配置的实现默认值，尚未作为用户最终偏好确认。

部署通过 `.env` 修改 `FSRS_DESIRED_RETENTION`、`FSRS_MAXIMUM_INTERVAL_DAYS`。`REVIEW_FUTURE_CLOCK_TOLERANCE_SECONDS` 默认 300，设备答题时间超过领先容差时拒绝提交并保留本地记录，不静默修改时间。调整参数影响后续调度，不重算历史。

`V9__review_events.sql` 建立不可变复习事件表，并给学习条目增加当前事件标识和自动耳词状态。SQL 保存在仓库，Flyway 按 V1～V9 初始化或升级。复习不会修改基准词典。

## 提交 API

登录用户调用 `POST /api/v1/learning/reviews`，账户归属来自认证会话，写请求需要 CSRF。示例中的时间和学习身份必须替换为当前用户的真实数据：

```json
{
  "eventId": "cfc6eaf0-15c3-4858-af20-60c755c73f6d",
  "attemptId": "f8e8c5cf-d25d-4f7c-8d45-e84f3b1c1a17",
  "learningItemId": "ab1e069c-badc-47b0-a789-a8165e1dd59d",
  "progressEpoch": "21b398d1-ce13-4fcf-9256-2d5e56b45055",
  "baseVersion": "0",
  "baseEventId": null,
  "submissionVersion": "2026-10-02T04:00:01.000Z",
  "completedAt": "2026-10-02T04:00:01.000Z",
  "results": [{
    "typeId": "LISTEN_RECALL",
    "contractVersion": 1,
    "trials": [
      { "id": "e9707f6f-a9b8-4f9b-9296-afab2e6f5fe0", "ratedAt": "2026-10-02T04:00:00.000Z", "rating": "AGAIN" },
      { "id": "f5509307-b830-4512-b0c5-11a1c82c9e64", "ratedAt": "2026-10-02T04:00:01.000Z", "rating": "GOOD" }
    ]
  }]
}
```

第一版服务端只接受 `LISTEN_RECALL@1`。试次标识不可重复，时间非递减，成功之前的试次必须为 Again，最后一次必须为 Hard 或 Good，完成时间等于最后判定时间，时间精度最多为毫秒。最终评分取所有尝试最差值，示例最终为 Again，只更新一次 FSRS。

初始 `baseVersion` 为 `0`，后续取学习条目返回的 `progressVersion`，同时携带 `lastReviewEventId` 作为 `baseEventId`。服务端从引用的事件快照计算，不用当前状态替换离线基准。基准事件尚未上传时返回 409，应先上传基准；同时间戳存在多个事件时必须指定基准 UUID。

返回 `APPLIED`（更新当前卡片）、`HISTORICAL`（保存较早答题的历史）或 `DUPLICATE`（确认完全相同的重传），响应始终携带当前最新进度。当前事件按实际完成时间比较，时间相同按 UUID 文本顺序稳定比较，与上传先后无关。次数统计所有唯一完成事件；重传不增加次数，复用 attemptId 换 eventId 返回 409。

`GET /api/v1/learning/items/{learningItemId}/reviews` 返回最近 50 条历史，按答题时间倒序。单词本项增加 `progressVersion`、`lastReviewEventId` 和 `automaticEarFocus`。Again/Hard 自动进入耳词重点，Good 不自动移除。

重置与提交使用相同的学习条目行锁，清空共享进度、历史和全部重点，并轮换 `progressEpoch`。旧代际提交返回 409，最后关联删除后旧学习身份返回 404；重新加入获得新 UUID。删除学习条目或账号会级联删除历史。

## 客户端训练和同步

每组最多 10 词，先完成本组一个题型再进入下一题型。Again 自动放入队尾；最后必做题型通过时，立即完成该词，不等待同组其他词。客户端保留题型列表、协议版本和逐题型试次；服务端开放新题型前仍需增加对应校验策略和必做题型快照。

`DexieReviewSessionStore.start` 固定批次基准；`rate` 在同一个 IndexedDB 事务中保存判定、队列和完成事件，写入失败整体回滚。`recordBrowserTrainingRating` 在词条完成后触发上传。未完成的词没有上传事件，也不更新 FSRS。

数据按 `[站点来源, 用户 UUID]` 分区。上传器按答题时间发送，每次请求前验证服务端账号；断网、会话过期或切换账号时停止并保留记录。自动与手动补传共享一次任务，上传期间新完成的词也继续上传。只清除明确确认的事件和词条草稿，未完成词保持队列；整批结束且全部确认后删除批次缓存。

单词本页显示待上传数量，提供“上传今日学习进度”按钮，补传所有积压事件，包括以前断网未提交的记录。本机删除/重置清理旧代际缓存并使涉及的离线准备失效；联网进入页面或上传前通过核对接口识别其他设备的变化，完整确认后撤销失效缓存。未知业务冲突保留原记录和中文原因，刷新后仍可重试或明确丢弃依赖链，其他独立词继续上传。接口错误码及清理边界见[多设备同步与冲突处理](./多设备同步与冲突处理.md)。离线准备完成后支持关闭页面重新打开。

## 验证与实际查看

离线 FSRS 调度已接入：学习视图返回卡片和部署参数，训练基准固定这些快照，完成事件及未确认投影原子保存。日队列允许按本地预估时间到期重入，连续轮次引用前一待上传事件；服务器确认后替换预估并清理。旧缓存缺少参数时保留答题但不猜测周期，详见[离线 FSRS 调度与验证](./离线FSRS调度与验证.md)。
