# 个人读音与例句覆盖

在“我的单词本”点击公开词条，进入“编辑我的内容”。个人覆盖附着于原学习身份，跨单词本共享；不修改基准词典，也不产生第二份学习进度。

## 使用与继承

- “使用个人读音”覆盖完整读音列表，可以添加、排序、移除读音，分别填写假名和发音文本。空发音不生成 TTS；移除全部读音后该词保留，但不能参加听音训练。
- “使用个人词义与例句”覆盖完整词义/例句列表，可填写例句正文、显式发音和译文。初次启用以当前显示内容为起点，保存后仅自己可见。
- 两个覆盖开关相互独立。只改例句时仍沿用公开读音及其公共音频；只改读音时仍沿用最新公开词义和例句。
- 简单“个人释义”与完整“个人词义与例句”互斥。完整覆盖关闭后，可用简单释义替换整组词义；笔记和标签仍保持私有。
- 关闭覆盖并保存，或确认“清空个人内容”，恢复继承最新公开内容。清空会同时清除个人读音、词义、例句、简单释义、笔记和标签，学习进度保留。
- 独立私有词条的读音与例句直接通过“编辑私有词条”维护，不在同一条目上叠加重复结构覆盖。

公开详情只展示基准内容，普通用户和管理员均不能通过本人以外的学习 UUID 读取、生成或重新生成个人音频。基准词条封禁后有效正文为空，个人覆盖不能绕过封禁参加训练。

## 版本、训练和离线

个人表单使用 `revision` 做并发检查，陈旧保存返回409并保留原表单，可重新加载。读音或完整词义/例句结构变更时，单独递增 `audioRevision`；仅修改笔记、标签或简单释义不递增。

结构变更撤销涉及该词的旧训练草稿和固定资源，使相关单词本下载需要更新；已经完成的待上传复习事件和未确认 FSRS 投影保留，可以继续补传。笔记、标签和简单释义修改继续保留正在进行的固定答案及原队列。

个人有效内容、读音和例句随单词本准备按站点/账号分区保存，支持断网关闭后冷启动继续听音回忆。正文编辑需要联网登录原账号。联网核对同时检查已下载内容及仅在详情播放过的个人覆盖音频，远程修改/删除不能使这些文件长期作为旧私人缓存残留。文件未变化时复用同一版本，并更新其结构版本元信息，避免反复取消新准备的训练。

重置任意单词本仍完整重置共享学习进度和手动重点，保留个人正文。最后关联删除清除个人覆盖、审计、学习记录及个人音频；只有一个分类关联被移除时，其他分类的共享进度保留。

## 音频生成和删除

个人覆盖音频使用 `OVERRIDE` 作用域，来源身份是本人 `learningItemId`，对象路径为 `audio/override/`。继承音频仍使用公共词条 UUID 和 `PUBLISHED` 作用域，不将私有发音文本传入公共生成入口。页面按读音和例句分别选择作用域；训练准备及音频修复使用同一契约。

后台“允许个人音频生成”同时约束独立私有词条和个人覆盖的保存、详情、点击及手动重新生成。关闭后已有内容匹配的正确文件仍可播放。生成复用跨进程行锁、唯一资源、任务租约、锁后复查和有界线程池；生成完成前再次核对源内容和配置。

关闭某类型覆盖时，事务内捕获该类型全部云版本，先解除当前版本与租约，再删除私人音频身份；云对象通过已有任务每分钟有界重试删除。最后关联删除同样捕获全部个人版本。生成中清除/删除的迟到上传不能重新创建私人内容，未切换成功的对象进入清理队列。

本机一次事务清除旧私人内容、训练资源及对应 `OVERRIDE` 音频，保留公共音频、其他账号和已完成待上传记录。缓存事务失败完整回滚并提示，不能伪装为复习已确认或清理成功。

## API 与 SQL

沿用 `GET/PUT /api/v1/learning/items/{itemId}/content`，保存请求增加：

```json
{
  "expectedRevision": 0,
  "meaningOverride": null,
  "notes": "我的笔记",
  "tags": [],
  "replaceStructuredContent": true,
  "readingsOverride": null,
  "sensesOverride": null
}
```

`readingsOverride` 为读音数组，`sensesOverride` 为包含例句的词义数组，子项字段与词典内容编辑器一致。`null` 表示继承，`[]` 表示明确覆盖为空。只有 `replaceStructuredContent: true` 才替换两个结构字段；旧请求省略该字段时保留现存覆盖，避免旧客户端保存笔记误清新内容。字段长度、子项数量与 UUID 校验复用词典契约。

响应增加本人原始覆盖和 `audioRevision`，学习列表增加 `personalAudioRevision`，与 FSRS 版本和重置代际分离。音频沿用 ensure/regenerate 入口，个人请求传 `scope=OVERRIDE` 及本人学习 UUID。

`backend/src/main/resources/db/migration/V13__personal_pronunciations_and_examples.sql` 保存新增列、音频学习身份外键、唯一约束及中文注释；JPA 和学习条目行锁负责事务。V1–V12 与 JMdict 初始 SQL 保留，不重新导入词典。IndexedDB 沿用 v5，只增加可选数据字段，不升级或清空旧数据。
