# 背词界面改版与测试

实现日期：2026-10-03。基于[MOJi参考方案](./MOJi背词模块调研.md)调整实际Web页面，继续使用现有FSRS、IndexedDB草稿和同步协议。本轮不新增数据库迁移或生产题型。

## 实际页面

- 首页“背词总览”进入`/learning`。按单词本显示封面、总词数、已学数、新词数和待复习数；已有活动草稿显示“继续训练”。封面只使用本项目生成的文字和颜色。
- “新建单词本”打开原生模态弹窗；保存成功后进入详情。关闭未提交表单仍保留本页内的输入，保存成功才清空。
- “学习列表”进入`/learning?book=UUID`。提供全部、未学习、待复习、学习中、耳词筛选；管理单词本菜单包含重置、删除，词条“更多”包含复习历史、移除。刷新和浏览器后退可保持详情位置。
- “开始复习”沿用`/learning/UUID/review`的资源准备流程。没有填写发音的词显示明确数量；有发音却未取得有效音频时不能开始。云凭据尚未配置时显示真实失败信息。
- 听音卡片显示整体完成数、本组剩余词数、播放按钮；播放成功后才能翻面。答案保留个人有效内容、笔记和标签；底部三档评分清晰区分忘记、困难、记得。
- 暂停返回详情后显示“继续听音训练”。每次判定依旧原子落盘，最后一词Again也会自动重试；每词完成后生成事件并尝试上传。完成界面明确显示仍待上传的数量。
- “上传今日学习进度”继续补传当前账号今日及此前所有积压记录。版本冲突处理和明确丢弃入口保留。

## 统计定义

词典的“已发布、私有、封禁”与学习阶段分开；封禁词条仍能在全部列表中看到，但不作为可复习的新词或到期词。

- 未学习：没有完整复习次数且没有最后答题时间。
- 已学/学习中：已完成过完整复习，不等价于永久掌握。
- 待复习：已学、可训练且周期已到；待同步但无法计算周期的记录不猜测为到期。新词单列，开始训练时仍按到期优先、新词其次。
- 耳词：手动重点或算法标记的听力重点。
- 今日已复习词：最后实际答题时间属于浏览器本地今天的共享学习条目数。按稳定学习ID去重，不按次数统计；跨本卡片分别展示各本分类，总览合并统计。

在线及离线展示均合并当前账号的本地已完成进度。某个单词本加载失败时显示统计未加载，总体数字显示“—”，不把失败当零。单本重置后重新读取所有单词本，避免另一个本的旧共享统计继续显示。

## 验证

Docker前端构建包含17个测试文件、101项测试及TypeScript检查，全部通过。新增统计测试覆盖共享身份去重、新词与到期词分离、未来周期、封禁、私人词条与未确认离线周期。

独立Docker项目使用真实PostgreSQL、认证、词典、FSRS与复习上传API；仅云音频替换为仓库内的测试音频，不调用真实Google或R2。Chrome验收覆盖：

1. 弹窗创建后关闭并进入详情，两个本引用同一学习身份。
2. 真实总览去重；新词、到期、学习中和耳词筛选；复习历史查询。
3. 云配置缺失时禁止开始，准备有效音频后到期词先于新词，翻面前隐藏答案。
4. Again自动队尾重试，暂停后关闭页面、断网重新打开，从IndexedDB恢复原队列。
5. 断网完成两个词、重新登录所属账号补传，最差Again仍由服务端保留。
6. 重置一个单词本，另一单词本的共享学习统计同步重置。
7. 桌面和390px手机布局、无横向溢出、无运行时错误。

测试数据只写入独立测试数据库，验收后移除该项目及其临时数据。实际预览只更新Web容器，不清空原数据库或浏览器缓存。

5174已验证提供新总览、训练脚本和样式，API健康状态为UP，界面更新前后数据库记录数量一致。随后按用户请求，通过既有初始化流程新建一个本地管理员，密码由应用使用BCrypt保存，配置保存在被Git忽略的`.env`中；已在真实5174预览验证登录成功及背词总览可访问。既有账户密码未被覆盖，完整作答验收仍在独立数据库中完成。
